# Contributing

## Issues

- Search existing issues before opening a new one.
- Provide source code and the commit SHA when reporting a bug.
- Review existing issues and provide feedback or reactions where helpful.

## Pull and merge requests

- Open pull or merge requests against `main`.
- Keep each pull or merge request to no more than two commits; squash additional commits.
- Ensure all configured continuous-integration checks pass.
- Add or update tests to cover the proposed changes.
- Document new features in the appropriate project documentation.
- Include a brief description of the approach taken and alternatives considered.
